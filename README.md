# La Madrina · Cabañas de altura

Sitio de una sola página de La Madrina Cabañas de altura (Apart Hotel La Madrina), Tafí del Valle, Tucumán.

- `index.html`: la página (español por defecto; inglés con el selector ES/EN o `?lang=en`).
- `css/styles.css`: estilos.
- `js/main.js`: mapa topográfico generado, idiomas, formulario de disponibilidad que abre WhatsApp, selector de cabañas, estado de check-in con la hora de Tucumán y línea de ruta del scroll.
- `img/`: fotos. Ver `img/LEEME-fotos.md` con los nombres exactos que espera la página.

Es HTML/CSS estático, sin pasos de compilación. Para publicarlo en GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
